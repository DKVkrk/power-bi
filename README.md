# ✈️ Flight Delay Analysis Dashboard  

A **Power BI Dashboard** that provides insights into **flight delays** by analyzing historical data.  
This project helps identify patterns, trends, and causes of delays, enabling airlines, airports, and passengers to make **data-driven decisions**.  

---

## 📊 Features  

- **Interactive Dashboard** with filters (airline, airport, date, delay type).  
- **Delay Insights**:
  - Delay by **airline** (carrier delay comparison).  
  - Delay by **airport** (busiest vs. delayed airports).  
  - Delay by **time of day** and **day of week**.  
- **Trend Analysis**:
  - Monthly/yearly delay trends.  
  - Seasonal flight delay patterns.  
- **Performance KPIs**:
  - On-time %  
  - Average delay duration  
  - Total flights vs. delayed flights  

---

## 🚀 Prepare Data

Dataset: Use US Flight Delay Dataset or any open-source flight delay dataset.
Place dataset (.csv or .xlsx) inside data/ folder.
Open in Power BI
Open FlightDelayDashboard.pbix in Power BI Desktop.
Load the dataset into Power BI.
Refresh data connections
